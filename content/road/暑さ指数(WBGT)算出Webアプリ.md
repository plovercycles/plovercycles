# 📋 熱中症予防 WBGT 算出 Web アプリ仕様書

身内のコミュニティ（数十人規模）において、屋外活動時の熱中症リスクを事前に、かつピンポイントに把握し、安全な活動運営（適切な休憩、水分補給の指示など）に役立てるための Web アプリケーション仕様書。

---

## 🛠️ 1. システム概要・構成

Google Apps Script (GAS) をベースとし、完全無料で Web 上に公開する。ユーザーはスマホや PC のブラウザから専用 URL にアクセスするだけで、特定の活動場所の最新 WBGT 値とリスク、行動アドバイスをリアルタイムに確認できる。

- **フロントエンド（UI 画面）:** HTML / CSS / JavaScript (GAS の Web アプリ機能で配信)
- **バックエンド（処理・計算）:** GAS (Google Apps Script)
- **データセット（気象 API）:** Open-Meteo API
  - **信頼性:** 日本国内のピンポイントな予測に強い **日本気象庁（JMA）の数値予報モデル** のデータを優先的に取得。
  - **コスト:** 完全無料（1日10,000リクエストまで無料枠があり、コミュニティ運用では十分余裕あり）。

---

## 📊 2. 機能要件（データ活用方針）

ユーザーが画面から「活動場所」を選択して実行した際、以下の**二段構え**でデータを表示する。

### ① 向こう 24 時間の 1 時間刻みの推移
- API から取得した「1 時間ごとの予報（気温・湿度）」を基に、現時点から 24 時間先までの WBGT 値を 1 時間刻みで算出。
- **画面表示:** 折れ線グラフまたはタイムライン形式。時間帯ごとのリスク推移（例: 「15 時までは厳重警戒、16 時以降は注意に下がる」など）を一目で把握できるようにする。

### ② 向こう一週間のピーク値（最大値）
- 今日を含めた今後 7 日間の 1 時間刻みデータから、**各「日」ごとの最高 WBGT 値**をプログラムで自動抽出する。
- **画面表示:** 週間天気予報のようなリスト（またはカード）形式。各日の「最大リスクレベル」を表示し、週末の活動計画や遠征の判断材料にできるようにする。

---

## 🧮 3. 計算ロジック ＆ リスク判定基準

### ■ WBGT 推定式（日本生気象学会等の簡易式に準拠）
API から取得した「気温（$T$）」と「相対湿度（$RH$）」から、以下の算式を用いて WBGT（℃）を算出する（小数点第 1 位まで表示）。

$$WBGT = 0.725 \times T + 0.036 \times RH + 0.0036 \times (T \times RH) - 4.224$$

### ■ リスク判定とコメント基準（環境省・日本スポーツ協会に準拠）
算出された WBGT 値に基づき、5 段階のリスクとアドバイスを動的に判定する。

| WBGT 値 | 段階（リスク） | 行動アドバイスコメント（基本テンプレート） |
| :--- | :--- | :--- |
| **21℃未満** | ほぼ安全 | 熱中症のリスクは低いですが、適切な水分補給は忘れずに。 |
| **21℃ 〜 25℃未満** | 注意 | 強い負荷がかかる行動では、定期的に水分・塩分を補給してください。 |
| **25℃ 〜 28℃未満** | 警戒 | 発汗量が増えます。30 分に 1 回など、意識的に休憩と水分補給を！ |
| **28℃ 〜 31℃未満** | 厳重警戒 | 熱中症のリスクが非常に高いです。激しい活動は避け、頻繁に休憩を。 |
| **31℃以上** | 原則運動中止 | 屋外活動は中止すべきレベルです。すぐに涼しい環境へ退避してください。 |

※ コメント内容は、コミュニティの具体的な活動内容（自転車、球技など）に合わせて、後から最適化・カスタマイズを行う。

## 🚀 4. 非機能要件 ＆ 将来の拡張性

- **利用人数:** 数十人規模（身内コミュニティ内でのシェア）
- **コスト:** サーバー代、API 利用料ともに **完全無料** で運用
- **動作環境:** スマートフォン（Android / iOS）および PC の主要ブラウザ
- **Android アプリ化:** 本 Web アプリの URL を「WebView（ウェブビュー）」で包むことで、将来的に手軽に Android アプリ（APK ファイル）化できる設計とする。
