# ロトルアについて
- ニュージーランド北島中央部にあるロトルアは火山の街  

https://maps.app.goo.gl/z6LtdQJGg6B5KtNE8

# Whakarewarewa(ワカレワレワ)自然公園
- その中にWhakarewarewa(ワカレワレワ)自然公園があり、中を網の目のようにMTBトレイルシステムが張り巡らされれている  
- 5日のライドのうち3日はここで走った

https://maps.app.goo.gl/HweD3QJf6xAVbA7g6  

- ロトルアの土は黄土色で一見粘土質に見えるが、火山灰質で超グリップする。ちょっと表面がしっとりする朝イチに走ってもまったく滑らない。
- バームは基本パチパチに固められている。
- すげー走るので日本より2割増しで上手くなった気がする

# Hero Dirt
newzealandmountainbikingが開催するHero Dirt Rotorua  
https://newzealandmountainbiking.com/tour/hero-dirt-rotorua/?srsltid=AfmBOoo3FNuYYW5e_K2vKQEg5cegvxWkWVjTvZFe-W8nCvk3ct82FSkL

- 全部で5日間のライド
- 最少催行人員3名
- 朝、宿まで来てくれてピックアップ
- 午前中はガイドと一緒にライド。場合によっては簡単なレッスン
- ガイドがダウンタウンの美味しいところへ運んでくれて一緒にランチ
- 午後はフリー。頼めば希望の場所でドロップしてくれる(自力で宿へ帰る)
- 夕方6時くらいに宿でピックアップしてくれて、ダウンタウンで一緒にディナー
- 8時くらいに宿まで運んでくれて終了×5日間

# Day1 3月1日
- お昼にロトルア空港着。NZMTBのガイドJamieにピックアップしてもらう
- パーク内のカフェでランチしてバイクをくみ上げ、さっそくライド

![[Pasted image 20260310161801.png]]


- ワカレワレワMTBパーク。ガイドは引き続きJamie

![[Pasted image 20260310161742.png]]


- 各ルートは1〜6までグレーディングしてあり、走る前にだいたいの難易度が分かる
	1. 1はほぼフラットなダート
	2. 2は緩いアップダウン
	3. 3は小さなギャップや根っこがあり、斜度も少しあってスピードが出る
	4. 4は辛うじて舐められるドロップやハイスピードなバーム、狭いシングルトラックなど。中級者という感じ。小さなテーブルトップもありバイクが浮くシーンがある。
	5. 5になるとジャンプはキャニオン、ドロップオフはバイクを浮かせないとクリアできない。斜度もかなり急で上級者向きかなという印象
	6. 6は落差数メートルのドロップオフなど…個人的には走れる気がしなかった。

![[Pasted image 20260310161824.png]]


- ワカレワレワMTBパークは全体的にフローでメンテナンスがされたルートが多い。とにかく楽しい！楽しい楽しい！最高過ぎる
- Grade2～4を走ってみて、Jamieは僕らのスキル具合をどの程度か確認したようだ。4本ほど走ってこの日は終了。一番難しいGrade4 が富士見パノラマのブルーホーネットより少し難しいくらい
- なお一人、トランジットの予約をミスしてこの日はオークランド観光(笑)

# Day5 3月5日
- ツアーの白眉。まさしくEPIC！
- この日はヘリコプターでの搬送ライド。Kaimanawa Alpine Adventure
- 出発地点はロトルアから約2時間

![[Pasted image 20260310162547.png]]

https://www.kaa.co.nz/

- ヘリで二千メートル付近？まで連れていかれ、そこから25KMで1100mダウン、400mアップ
- とにかく景観が素晴らしい。完全に海外のライドのそれ。これで3人とも完全に脳が焼かれてしまった

- トレイルも手入れされており走りやすい。前半は荒涼とした山道を走り、後半は熱帯雨林の中を快走するシングルトラック。スムーズ！適度にツイスティ！程々の斜度！くっそ気持ち良い！
