シマノのグラビティシューズのエントリーライン、SH-GF400を購入した。テストは、ふじてんとパンプトラック千葉で実施  

# 購入したもの
メーカー：シマノ  
モデル：SH-GF400  
カラー：ネイビー  
サイズ：42  
重量：384g(公称)  
購入：シマノオンラインストア  
# デザイン
シマノのロゴが大変控えめ。色味も含めて悪くないと思います。シマノさん結構ダサいと言われてるの気にしてる？靴紐の通るアイレットが長穴で紐が途中でよじれない。最高(笑)  
ファブリック素材なので通気性良い。冬場は冷えるかも

# フィット感
シマノのロード、マウンテンと同じサイズの42を選んででちょうど良かった  
はじめ小指側に軽い圧迫感があったが靴がなじんだのかしばらくしたら問題なくなった  
踵にシリコングリップとかはないが、踵の浮きとかもなく、普通に良いです  

# ソール
剛性割とある  
結構薄めでダイレクトな踏み味。ピンが長いペダルだと母指球付近に違和感出るかも？  

# グリップ
ペダルはDMRのVAULTを合わせました。グリップは大変良い。5.10と遜色無い、というかむしろちょっと良いかも？薄いソールと相まって好印象

# その他
トレイルでは小石、砂がシューズに入る。ハイエンドラインはソックス構造で入りにくいのでこれはコスパ勘案して選べばよさそう  

価格はGWセールで15%オフ。シマノは頻繁にセールしてくれるのでセールのタイミングで買うのが良さげ  

# 総評
トレイルシューズのエントリーモデルとして申し分ない。セールを狙えば一万円ちょっと。コスパ良好
トレイルシューズは5.10がアディダス傘下になって入手性が悪化しており、シマノのグラビティシューズがそれに代わるかなと感じている
